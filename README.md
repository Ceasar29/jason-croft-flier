# Jason Croft — Sherwin-Williams digital flier

Live page: https://ceasar29.github.io/jason-croft-flier/

| File | What it is |
|---|---|
| `index.html` | Main digital flier (phone-first). The top QR code on the printed flier opens this. |
| `classic.html` | Same layout as the original paper flier, with clickable tiles. |
| `print-pro.html` | Printable letter-size marketing flier, new design (margins None, background graphics on). |
| `print.html` | Printable letter-size flier in the original paper layout. |
| `img/` | Photos, logo and both QR codes. |

## Changing contact details
Open `index.html` and edit the `JASON` block near the bottom (name, title, phone, email, service area).
Every button, the contact panel and the "Save contact" card read from it.

## Moving this to your own GitHub account
1. Create a free account at github.com.
2. Create a new public repository, upload these files, then Settings → Pages → Deploy from branch `main` / root.
3. Your page will be at `https://<your-username>.github.io/<repo-name>/`.
4. Tell Elgin the new address. The old address keeps working: it becomes a one-line page that forwards to yours,
   so fliers already printed keep scanning correctly.
